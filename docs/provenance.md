## Repository evidence

Git history is the primary record of revision and authorship chronology.

Important distinctions:

- a commit proves that a repository state existed at a given point in its Git history
- a commit does not independently prove scientific validity
- a generated identifier is not a cryptographic signature unless explicitly implemented as one
- a placeholder CID is not evidence of an IPFS upload

## External publication

Before any artwork or metadata is uploaded, minted, or submitted, record:

- final asset filename and checksum
- license and rights holder
- IPFS CID, if created
- network and contract address, if deployed
- token ID and transaction hash, if minted
- publication date and destination

No identifier should be recorded as final before it exists and can be independently verified.
