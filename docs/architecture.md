# Architecture

## Project hierarchy

```text
quantumart-protocol-2026-official
  └── defines principles, ethics, terminology, and publication structure

quantum-shogi-silent-nft
  └── tests one experimental implementation
```

## Internal structure

```text
index.html
  └── public entry point for GitHub Pages

  ├── Born-rule-inspired probability interface
  ├── shogi-like candidate generation
  ├── RadicanTrust™ experimental HUD
  └── NFT metadata draft generation

docs/
  ├── architecture.md
```

## Naming hierarchy

- **Quantum Shogi**: primary project and interaction system
- **Silent NFT**: one experimental module within Quantum Shogi
- **QuantumArt Protocol 2026**: canonical parent framework

## Boundary

This repository is a reference implementation and artistic prototype. It is not an audited smart contract, certified scientific instrument, or official IYQ2025 project.
